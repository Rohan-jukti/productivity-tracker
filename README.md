# Productivity Tracker Chrome Extension

## 📌 Overview

This project is a Chrome Extension designed to improve productivity by tracking time spent on websites, blocking distracting sites, and generating daily reports.

## 🚀 Features

* Tracks time spent on different websites
* Blocks distracting websites (YouTube, Instagram, Facebook)
* Generates daily productivity reports
* Stores data using MongoDB

## 🛠️ Tech Stack

* JavaScript (Chrome Extension)
* Node.js
* Express.js
* MongoDB

## ▶️ How to Run

### 1. Start Backend

cd server
node server.js

### 2. Load Extension

* Open Chrome
* Go to chrome://extensions/
* Enable Developer Mode
* Click "Load Unpacked"
* Select client-extension folder

## 📊 Usage

* Browse websites normally
* Blocked sites will be redirected
* Click extension icon → Load Data to see report

## 🎯 Result

A fully functional productivity tracking extension with real-time monitoring and reporting.
